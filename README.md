A small program that writes one sentence — a pedestrian crossing beeps, strangers step off the kerb in unison, and for eight seconds the whole street agrees on something — to `/output/entry.txt` for make.fun's Everyday Wonder bounty.

## Run it

```sh
node main.ts
```

It writes exactly one line (122 characters, no trailing newline) to `/output/entry.txt`, deterministically: the same bytes on every run, from any working directory. No input, no network, no secrets.
